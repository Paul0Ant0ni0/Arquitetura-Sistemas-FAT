# Projeto Prático — Arquitetura de Sistemas

Repositório destinado ao desenvolvimento do projeto prático do curso de **Arquitetura de Sistemas**, com foco na aplicação de conceitos de desenvolvimento back-end, construção de APIs RESTful, persistência de dados e boas práticas de arquitetura de software.

O projeto utiliza o ecossistema Java para desenvolver uma aplicação estruturada, explorando tecnologias e ferramentas amplamente utilizadas no mercado.

## 🛠️ Tecnologias e ferramentas

- **Java** — Linguagem de programação.
- **Spring Boot** — Desenvolvimento e configuração da aplicação back-end.
- **Spring Data JPA / Hibernate** — Mapeamento objeto-relacional (ORM) e persistência de dados.
- **H2 Database** — Banco de dados para desenvolvimento e testes.
- **Postman** — Testes e validação dos endpoints da API REST.
- **Maven** — Gerenciamento de dependências e build do projeto.

## 🎯 Objetivos de aprendizagem

- Aplicar conceitos de arquitetura de sistemas.
- Desenvolver e testar APIs RESTful.
- Implementar operações CRUD.
- Compreender o mapeamento entre entidades Java e tabelas do banco de dados.
- Trabalhar com persistência e manipulação de dados.
- Aplicar boas práticas de organização e manutenção de código.
- Validar requisições HTTP utilizando o Postman.

Este repositório será atualizado ao longo do curso, documentando a evolução do projeto e a aplicação prática dos conhecimentos adquiridos.
